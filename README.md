# 🐱 Кокос Кликер (Kokoc Clicker)

**Кокос Кликер** — это текстовая игра на Python, в которой вы гладите кота Кокоса, зарабатываете баллы, покупаете ему шляпы и следите за его настроением!

## 🎮 Как играть

1. Скачайте файл `кокос_кликерV2_1.py`.
2. Откройте его в любом приложении для запуска Python (например, **Pydroid 3** на Android или IDLE на ПК).
3. Запустите скрипт.
4. Нажимайте **Enter**, чтобы погладить Кокоса (и получить баллы).
5. Вводите команду **«магазин»**, чтобы купить шляпу.
6. Вводите команду **«Выйти»**, чтобы завершить игру.

## 🎩 Шляпы

В магазине можно купить:
- **Корона Кеида (кокос edition) 👑** — 50 баллов.
- **Шляпа ^** — 30 баллов.
- **Шляпа Чебурек 🥟** — 100 баллов.
- **Снять шляпу** — 0 баллов.

## 😸 Эмоции Кокоса

Кокос может быть:
- **Обычным** (`o.o`).
- **Счастливым** (`^.^`).
- **Спящим** (`-.-`, с `Z`).
- **Злым** (`>.<`).
- **Влюблённым** (`♥.♥`).

А ещё он иногда **засыпает** (если его слишком часто гладить) и просыпается через несколько кликов!
